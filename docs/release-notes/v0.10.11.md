## Glass Panes v0.10.11 (public beta)

You can now see what every display is showing without hunting for it.

### What changed

- **A "Showing" strip at the top of the builder.** One chip per display, such as "Hall mirror: House". It is there on every tab, so the Panes tab no longer hides which pane is live. Open a chip to switch that display to a different pane. It does exactly what the Showing choice on the Displays tab does. With several displays the strip scrolls sideways on a narrow window. With none, it offers **Add a display**.
- **A "Showing on ..." tag on pane cards.** A pane that a display is showing carries a small tag for each display. Click a tag to jump to that display in the Displays tab. A pane nothing is showing has no tag.
- **They keep up on their own.** When an automation switches a display, the strip and the tags change within a moment. You don't reload.

- **A themed pane can stay true black.** On a two-way mirror only pure black is see-through, so a theme's lit background, even Cream Night's very dark one, shows as a visible rectangle. A dark theme (Moss, Cream Night, Midnight, Slate) now starts on true black with the theme's text colours. A **Theme background** box next to Theme brings the theme's own background back, and the Background colour works while it's unticked. The light themes (Cream, Paper) keep their own light background, because their dark text needs it. The toolbar now says "Black is see-through on a mirror." Panes that already have a theme look exactly as they did; nothing changes until you pick a theme again. In the pane file this is `own_background`.

### Install or update

HACS > Glass Panes > **Download**, then restart Home Assistant (Settings > System > the power icon > Restart Home Assistant), because the pane format gained a field and Home Assistant only learns it at start-up. Then reload the builder page once. Your panes, uploads and logins stay as they were.

### Known limits

- The strip and tags have been checked in the builder preview with made-up displays, not yet in the live Home Assistant sidebar.
- Switching from a chip needs an administrator account, like the rest of the builder.
