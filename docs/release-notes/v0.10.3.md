## Glass Panes v0.10.3 (public beta)

### What changed
- **Sports: "Only on game day".** A new switch on the sports widget (Edit, click the widget, **Only on game day**). On, sports show only live games, tonight's game, and a final only until midnight, and a later game is never announced. Off (the default) keeps a final for about 18 hours, so last night's score is still there in the morning. In the example panes, the `mirror` and `house` panes now use it, and the `morning` pane no longer lists upcoming games but still shows yesterday's score.
- **Signed mirror app is now attached to the release.** v0.10.2 was meant to carry it, but the signed build stopped on a crashing lint check. That check is switched off for release builds, and the signed `mirror-kiosk-v0.10.3.apk` is built and attached by this release. Apart from the sports switch above, nothing in the integration changed since v0.10.2.
- **Mirror app (same code as v0.10.2):** removal cleanup and signed releases from v0.10.2, plus the built-in rotation setting (`http://<mirror address>:8099/rotation/portrait`, or `portrait_reverse`, `landscape`, `landscape_reverse`, `auto`). The rotation setting has not been tested on a mirror yet.
- **How to check the download is genuine:** the signing certificate's SHA-256 fingerprint is in `docs/mirror-app/install-app-lululemon-studio.md` (step 3).

### Install or update
HACS > Glass Panes > Download. No restart is needed (nothing in the integration's Python code changed since v0.10.2). Updating keeps your panes, uploads and logins.

**Mirror app:** this is the first signed APK, so a mirror that already has a CI test build must uninstall it once first (this erases the app's settings: write down the page address, login and webhook), then install this APK and set it up again. After that, every release installs over the top with `adb install -r` and keeps the settings. Steps: `docs/mirror-app/install-app-lululemon-studio.md`.

### Known limits
- The ready-made Android images for the mirror are not published yet.
- Fonts are a small bundled set; formal fonts and pane colour themes are next.
- Only English so far.
