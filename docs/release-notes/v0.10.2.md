## Glass Panes v0.10.2 (public beta)

### What changed
- **Removing the integration cleans up after itself.** Deleting Glass Panes (Settings > Devices & services > Glass Panes > Delete) now deletes every display's login user and its tokens. Your panes, display list, bindings and uploads are kept, so adding it again brings your work back (press **Set up login** again on each display).
- **Mirror app: signed releases.** The app APK attached to this release is signed with the project's release key, so later releases can update it in place and keep its settings. 
- **Mirror app: built-in rotation.** `http://<mirror address>:8099/rotation/portrait` (or `portrait_reverse`, `landscape`, `landscape_reverse`, `auto`) turns the picture without changing any Android setting. It is remembered and shown in `/status` as `orientation`. The default, `auto`, changes nothing. Not yet tested on a mirror.

### Install or update
HACS > Glass Panes > Download, then **restart Home Assistant** (the removal cleanup is Python code, which Home Assistant only loads at startup). Updating keeps your panes, uploads and logins.

**Mirror app:** the first signed APK cannot be installed over a CI test build (a different signing key), so on a mirror that has a test build, uninstall once first (this erases the app's settings: write down the page address, login and webhook), then install the signed APK and set it up again. After that, every release installs over the top with `adb install -r` and keeps the settings. Steps: `docs/mirror-app/install-app-lululemon-studio.md`.

### Known limits
- The ready-made Android images for the mirror are not published yet.
- Fonts are a small bundled set; formal fonts and pane colour themes are next.
