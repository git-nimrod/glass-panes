## Glass Panes v0.12.1 (public beta)

A small clean-up of v0.12.0.

### What changed

- **The Widgets catalogue screen is gone for now.** It showed every kind of widget in a separate window, but its previews were rough and it sat apart from where you build panes. Adding widgets works as before, from **Add** while you edit a pane. A better catalogue, inside the edit area, is on the [roadmap](https://github.com/git-nimrod/glass-panes/blob/main/docs/roadmap.md).
- An unbound widget still says what it needs ("Needs: a weather entity").

### Install or update

HACS > Glass Panes > the three dots > **Redownload**, pick **v0.12.1**, then reload the builder page. Only the builder changed, so no restart is needed. No new mirror app.

### Known limits

The same as v0.12.0. See the [v0.12.0 release notes](https://github.com/git-nimrod/glass-panes/blob/main/docs/release-notes/v0.12.0.md).
