## Glass Panes v0.12.0 (public beta)

The biggest update since the beta started: icons, colours that follow your data, a table, a widget catalogue, warnings you can edit, groups you can reuse, pairing a mirror with a code, controls for the mirror in Home Assistant, and a mirror that comes back by itself after a power cut.

### Highlights

- **A mirror that starts up properly after a power cut.** With Mirror app 0.12.0, the loading screen no longer stays stuck over a page that is already working, and the app no longer restarts itself for no reason when the mirror's clock jumps from 1970 to today. Recommended for everyone (details below).
- **Pair a mirror with a six-digit code** instead of a long command with a token in it.
- **Icons, tiles and chips, a Table widget, and colours and sizes that change with a value.**
- **A widget catalogue, editable warnings, reusable groups, a snap grid and zoom** in the builder.
- **Brightness and presence for the mirror as Home Assistant entities**, plus a blueprint that brightens the mirror when someone walks up.

### What changed

**Icons and looks**
- **Icons:** a bundled library of 7,400+ Material Design Icons (Apache 2.0). Add an **Icon** from Facets, or give an Entity value an icon beside its number. Choose one with the search box, or pick **Entity's own** to use the icon the entity already has in Home Assistant. The display never downloads the library: it asks Home Assistant for just the icons a pane draws (a few hundred bytes each), so the mirror holds no icon data it does not draw. In a test with a dozen different icons that was about 8 KB over one request instead of about 1.6 MB over ten.
- **Tiles and chips:** an Entity value can now be drawn as a **tile** (a rounded card with the entity's icon in a tinted circle, the name over the value) or a **chip** (a small pill with the icon and the value). Pick Look in the widget's More options. A colour-by-value rule tints the icon while the words keep your theme's colours.
- **Dividers:** five line styles (solid, dashed, dotted, double, fade), and a **box** look: a rounded outline, with an optional soft fill, that frames a group of widgets.
- **Colours and sizes by value:** on any widget with an entity (Entity value, Progress ring, Icon and so on), "Colours and sizes by value" changes its colour, size, weight, opacity or icon when the value is above, below, between or equal to something. The first rule that holds wins.
- **A Table widget:** each entity you bind is a row; each column shows the entity's name, its state, one attribute or fixed words. Times, dates, relative times, **durations** ("1 h 15 min") and numbers are formatted for you, and each column can have its own colours by value. A calendar-style sensor with start, leave-by and drive-time attributes becomes one tidy row.

**News and sports**
- **News: teaser headlines and video items are skipped.** A headline on a mirror has to make sense at a glance, so the News widget now drops headlines that only invite you into the article ("ERs are losing money. Here's why", "What it means for you", "The hidden cost of ..."), and items that are really a video, a livestream, audio or a photo gallery (WATCH:, LISTEN:, "in photos" ...). A headline that states a number stays even when it starts like a label. This joins the existing rules that skip questions, explainers and very long headlines.
- **Sports: "Headline above the logos".** A new option for the rows layout (`head_top`, in the widget's More options) puts Final, Live or "Today · 7 PM" above the two logos instead of beside them, so a game fits a narrow column.

**The builder**
- **A widget catalogue:** the **Widgets** button shows every kind of widget with a live preview, one line about what it does and what to bind to it. While you edit, a card can add its widget to the pane. An unbound widget now says what it needs ("Needs: a weather entity").
- **Warnings you can edit:** the Status summary's checks are cards: pick the entity, a name, when to warn (is, is not, above, below, unavailable) and the words to show.
- **Reusable groups:** select two or more widgets and press **Save as a group**. It appears under Add, Groups, and drops into any pane with its widgets, look and entities.
- **Snap grid and zoom:** choose a 10, 20 or 40 px grid, or none, and zoom the editor with buttons or Ctrl and the mouse wheel.
- **A widget placed below another keeps its link when you drag it.** Dragging up or down changes the gap, sideways moves it across, and **Unlink** removes the link.
- **Lighter Now playing:** the cover is now shrunk by Home Assistant to the size the widget draws it, instead of the mirror loading a full-size cover twice, and the soft glow behind the card uses a tiny copy with no blur filter. If Home Assistant cannot shrink a cover, the full one is used as before.
- **Clearer messages:** a tooltip about something that does not fit names the widget you named, not an internal id. A pane with nothing on it says so on the display, dimly, for a few minutes. The toolbar wraps on a tablet, and name tags no longer pile up when you select several widgets.

**Displays and the mirror**
- **A time zone on each display:** the Displays page shows it and lets you change it. Leave it empty to follow Home Assistant's own zone, so a daylight-saving change is picked up. The **Actions** screen no longer insists on a name when you only change a zone.
- **Pair a mirror with a code** (mirror app 0.12.0): a mirror that is not set up shows a six-digit code and its address. Press **Pair a mirror** on the display, type them in, and Home Assistant sets the mirror up, including its login, with nothing to copy. The older command still works.
- **Controls for the mirror in Home Assistant:** a display with its mirror set up gets a **Brightness** number and a **Presence detection** switch. They show the mirror's real settings.
- **A blueprint** that brightens the mirror when someone is there and dims it a while after they leave. Import it from `blueprints/automation/glass_panes/presence_brightness.yaml` (Settings > Automations & scenes > Blueprints > Import Blueprint).

**For agents**
- Agents can set colours by value on widgets, and add a group you saved, through the draft tools. `get_schema` describes icons, tables, dividers and warning checks. See [agents.md](../agents.md).

### Mirror app 0.12.0

Released alongside this as its own pre-release (`app-v0.12.0`). It fixes starting up after a power cut (a loading screen that could stay over a working page after a slow Wi-Fi start, and a pointless app restart when the clock jumps) and adds pairing with a code. The start-up fix is recommended for everyone; pairing needs it. See the app's release notes and [compatibility.md](../compatibility.md).

### Install or update

1. HACS > Glass Panes > the three dots > **Redownload**, pick **v0.12.0**.
2. **Restart Home Assistant** (Settings > System > the power icon > Restart Home Assistant), because this version adds Python parts (the new controls, groups and pairing).
3. Reload the builder page.
4. On the mirror: `adb install -r mirror-kiosk-v0.12.0.apk` from the `app-v0.12.0` release keeps your settings. The [update guide](https://github.com/git-nimrod/glass-panes/blob/main/docs/mirror-app/update-app.md) has every step.

Your panes, uploads, bindings and display logins are kept.

### Known limits

- The new builder features were checked by automated tests (the browser tests drive the builder against pretend data) and in the preview at phone, tablet and desktop sizes. The tablet layout has not been tried on a real tablet.
- Pairing, the brightness number and the presence switch were tested against a pretend mirror. The pairing screen has not been tried on a real mirror yet. The code and the login travel over your home network as plain `http`, like the rest of the traffic between the mirror and Home Assistant: pair on your own network.
- The Brightness number shows as unknown until a value has been set, because Android is in charge of the backlight until then. A brightness of 0 is as dark as the panel goes, not off. A screen on and off switch is not included yet.
- Colours by value work on widgets with a single entity and on table columns. A table's rows are entities, so a row cannot mix values from different entities.
- A group saved with entities keeps those entities. Drop it into another pane and it shows the same ones until you change them.
- The headline filter is a set of English wording rules. It will now and then drop a fine headline or keep a teaser; tell us which ones.
- Starting up still waits for the mirror's Wi-Fi, which on the tested unit takes one to two and a half minutes after power-on.
- The Bluetooth proxy and the voice assistant do not exist yet. The [roadmap](https://github.com/git-nimrod/glass-panes/blob/main/docs/roadmap.md) says what is planned.
