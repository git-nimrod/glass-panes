## Glass Panes v0.10.1 (public beta)

### What changed
- **Sports widget:** when every game in the list is a "vs" game (nothing scored yet), the two team logos now sit close together instead of far apart. Lists with scores keep their old spacing so the columns line up.
- **Mirror guides:** a new guide for putting Android on a Lululemon mirror (fastboot, flashing, Wi-Fi with scrcpy), a getting-started guide, a troubleshooting page, and a rotation step for a mirror that starts sideways. Written from one tested unit; see `docs/mirror-app/`.
- **Mirror app:** version number only (0.10.1). No code change.

### Install or update
HACS > Glass Panes > Download. No restart is needed for this release (only the player's style and script changed). Updating keeps your panes, uploads and logins.

### Known limits
- The ready-made Android images for the mirror are **not published yet**.
- Fonts are a small bundled set; formal fonts and pane colour themes are next.
- Only English so far.
