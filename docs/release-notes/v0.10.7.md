## Glass Panes v0.10.7 (public beta)

A stability and security release, and a big step towards showing any entity well.

### What's new

- **Any entity reads properly.** Dates and times show as "12 min ago", "tomorrow 7:15 am" or "Fri, Nov 20" in your display's timezone, instead of numbers like "2,026". Versions, IP addresses and ZIP codes stay as text. Thousands round correctly (1,234.6).
- **Home Assistant's own words for states.** A door says "Open", a person "Away", an update "Update available", an alarm "Armed away". Turn it off per widget with **raw state**.
- **Show an attribute.** The value widget can show an attribute instead of the state: a thermostat's target temperature, a cover's position, the sun's next rising.
- **Progress rings are honest.** 21 °C no longer shows as "21%", a number entity's own range is used, and the ring is only suggested first for real percentages (battery, humidity).
- **News and Status fixes.** A news widget added in the builder no longer says "Slow news day." forever, and a status summary no longer says "undefined offline".
- **People** can now also show device trackers. **Media artwork** prefers the copy Home Assistant serves itself, so the mirror doesn't need the internet.

### Security

- A crafted link could make a player page send its saved login to another address. When the player is served by Home Assistant (the normal case) it now only ever talks to that same Home Assistant, and it never reads Home Assistant's own saved login. **Update recommended.**
- Stricter checks on ids, on mirror answers and on new mirror keys (at least 8 characters).
- The builder and docs now say plainly what a display's login can do: it can control devices like any ordinary user, so keep its link private.

### Install or update

HACS > Glass Panes > **Download**, then **restart Home Assistant** (Python changed). Then reload the mirror's page once (`http://<mirror address>:8099/reload`) so it picks up the new player.

### Known limits

- State words are English, and sensors with integration-specific states (enum sensors) still show their raw state.
- No mirror app update in this release.
