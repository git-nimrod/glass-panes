## Glass Panes v0.10.0: public beta

The first public beta. It is used daily on a real smart mirror, but expect rough edges. Please report what you find.

### What's in it
- **Sidebar builder** (admins only): drag and drop on a snapping 1080 x 1920 canvas, resize, align, undo, save. Pick any of your own entities and Glass Panes suggests the right widget. **Facets** are the things that need no entity (clock, date, text, picture, video, divider, message).
- **Pictures and looping videos** uploaded from your computer or phone (protected storage, never public).
- **Displays**: each gets a `select` entity and a button per pane, so your automations decide what it shows.
- **First-time login per display**: one button makes a limited login for that display. No token pasting.
- **Share panes** as files (Export / Import). Only layout travels, never entities or uploads.
- **Services for automations and AI agents** that build panes with the same checks as the builder (see `docs/agents.md`).
- Light (cream) and dark (forest green) looks, a Mirror view that shows the display behind glass with its edges marked, and a readability warning for hard-to-see text.

### Install or update
HACS > Custom repositories > `https://github.com/git-nimrod/glass-panes` (Integration) > Download, then restart Home Assistant. Updating keeps your panes, uploads and logins.

### The mirror app (separate part of this repository)
The Android kiosk app for physical mirrors is in `mirror-app/`, with a step-by-step guide to putting it on a mirror in `docs/mirror-app/install-app-lululemon-studio.md`. It compiles in CI, but its new parts (boot screen, memory numbers in `/status`, presence settings) have **not yet been run on a physical mirror**. The Home Assistant integration works on its own without it.

### Known limits
- Home Assistant cannot restrict a user to certain entities, so a display's login can read what any ordinary user can (it cannot change settings and only works from your home network).
- Fonts are a small bundled set; formal fonts and pane colour themes are next.
- Only English so far.
- Warnings (doors, cameras, litter and so on) can be set up with services; a point-and-click editor is not built yet.

### Reporting problems
Open an issue (the form asks for the version numbers we need). Never paste tokens or webhook addresses.
